# G3 — Ready to plan?

> A concrete gate profile. It fills the slot contract defined in `references/ready-guide.md` and **inherits** the 7-step flow, the five leashes, and the autonomy check from that base. It does **not** restate the flow. The `/dev-ready` command binds this profile when the resolved break is G3 (a `…-design.md` **and** its `…-design-review.md` twin both exist — the review twin has advanced the cursor from G2 to G3).

**Break**: `/review-doc` → **[G3]** → `/dev-plan`

The design has been reviewed; the question is whether it is ready to be turned into a plan — or whether the right call is **don't plan it at all**. G3 is the one gate whose verdict can be **go/no-go**: a reviewed design that turns out not to be worth building should be archived, not planned.

---

## Required slots

### inputs

- `docs/[milestone-slug]-[task-slug]-design.md` — the reviewed design.
- `docs/[milestone-slug]-[task-slug]-design-review.md` — its review twin (its presence is what advanced the cursor to G3). G3 reads **both**.

### rubric (the fixed checklist — G3's identity)

Walk these inline, in order, against the design + its review twin:

1. **Review findings resolved.** The `/review-doc` findings on the design have been addressed (or consciously accepted with a rationale). An open HIGH finding that would reshape the approach blocks planning.
2. **Design will yield autonomous steps** *(autonomy smell test)*. *"Will planning this design produce autonomous steps, or does the approach bake in a spike / human-gate / operator-driven step that no plan can make autonomous?"* This is the **light** smell test (no executable steps exist yet — that per-step verdict is G4's job); here it asks whether the design's *shape* will let the planner write autonomous steps.
3. **Residual de-risking.** Any high-risk unknown the review surfaced that would still shape the plan is resolved — so planning lands grounded, not on open questions.

> G3 also makes the **go/no-go** call: given the reviewed design, is this still worth building now? A design that the review revealed to be low-value, redundant, or out-of-season should be **archived / not planned** — a no-go is a valid, bounded G3 outcome.

### verdict semantics

- **READY** = **ready-to-plan** — findings resolved, the design will yield autonomous steps, residual de-risking done; proceed to `/dev-plan`.
- **NOT-READY** = an unresolved finding, a non-autonomy bake-in, or open de-risking blocks planning; emit the **shortest in-scope action list** (e.g., "resolve design-review HIGH #2 before planning," "de-risk the open integration question").
- **go/no-go (don't-plan / archive)** = the reviewed design is no longer worth building — recommend **archiving** it rather than planning. This is G3's distinguishing verdict.
- **escalate: re-scope** = the path to ready is a sprawl (the review surfaced a re-architecture, not a short diff) — hand back to re-scope.

---

## Tunable slots

### allowed remedy classes

**Override** — base default **doc-edit / spike / scope-out / escalate**, **extended with archive / don't-plan** (G3 is the one gate that adds these).

- **doc-edit** — resolve a finding or tighten the design in place before planning.
- **spike** — resolve a residual high-risk unknown before planning rather than planning around it.
- **scope-out** — defer an out-of-scope sub-area to a later task.
- **archive / don't-plan** *(G3's extension)* — the reviewed design is not worth building; recommend shelving it instead of producing a plan. The go/no-go remedy that no other gate carries.
- **escalate** — when ready is a sprawl, hand back "escalate: re-scope."

---

## Notes

- **The go/no-go gate**: G3 is the one break where "don't build this" is a first-class, bounded outcome. Its **archive / don't-plan** remedy classes (extending the base default) and its go/no-go verdict are what distinguish it — after a review, the honest answer is sometimes *shelve it*.
- **Light autonomy check**: like G2, G3 has no executable steps to walk, so the autonomy concern is a smell test about the design's *shape* (*"will this yield autonomous steps?"*), not G4's per-step verdict.
- **No weight slot**: G3 runs **inline** like every gate. Its depth is light (a smell test over design + review twin), set by the inputs that exist, not a tunable knob.
- **Bias to READY**: a minor unresolved review nit that does not reshape the approach is "nit — proceed." Block only on an unresolved finding that would reshape planning, a non-autonomy bake-in, or a genuine no-go.
